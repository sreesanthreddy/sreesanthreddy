03 · The AI & the architect

Two systems, one workflow.
The future is cooperative.

I don't believe AI replaces the architect — I believe it expands the surface a single architect can design and operate. Claude reviews my pull requests. Cortex Code refactors my stored procedures. MCP servers give my agents governed access to the same systems I'm trusted with. The work becomes higher-leverage, not lower-skill.

Every system I architect today is built with both in mind: human-readable for the engineers who maintain it, machine-grounded for the agents that operate it.

04 · Approach

A few principles I architect by — every project, every audit, every quarter.

/01

Outcomes over outputs.

Scope work to a measurable business outcome — cost reduction, latency target, audit pass, time-to-onboard — and architect backwards from there.

/02

Governed by default.

Row-access policies, masking, audit trails, PrivateLink, KMS — designed in, not bolted on. Compliance is a property of the platform.

/03

AI where it earns its keep.

Anthropic Claude, Cortex Code, RAG — applied to NL analytics, governed self-serve, migration acceleration. Token budgets per workspace, evals before production.

/04

Everything as code.

Pulumi for infra. GitHub Actions for SQL deploys. PR-gated cost regressions. The platform you can recreate in a weekend survives reorgs.

/05

Cloud AI, native — not bolted on.

AI shouldn't live in a sidecar microservice nobody owns. Cortex Code and Claude run inside the same governance, observability, CI/CD perimeter.

/06

Boring is a feature.

Same architecture should behave the same at 50K and at 300K. Predictable beats clever. The 3 a.m. pager is the real architecture review.
