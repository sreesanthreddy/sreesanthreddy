# Drop your photos here

Save each photo with the **exact filename** below. The site will pick them up automatically.

```
assets/me-portrait.jpg    ← close-up headshot (black blazer)
assets/me-office.jpg      ← full body standing in office
assets/me-desk.jpg        ← at desk with laptop
assets/ai-chibi.jpg       ← cute white chibi robot
assets/ai-panther.jpg     ← black robotic panther/cheetah
assets/ai-handshake.jpg   ← you + humanoid white robot touching fingers
assets/ai-duality.jpg     ← side-by-side composite (you + AI robot)
```

Recommended: JPG, ≤ 1600px wide, ≤ 400 KB each.

If any image is missing, the site shows a small "// drop X.jpg into /assets" placeholder in that spot — no broken-image icons.
